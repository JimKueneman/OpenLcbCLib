◆ ProtocolConfigMemStreamHandler_run()

void ProtocolConfigMemStreamHandler_run ( void )

Drives the config-mem stream data pump.

Called once per main loop iteration from OpenLcbConfig_run(). State machine:

  • IDLE: nothing to do
  • WAIT_INITIATE_REPLY: waiting for stream accept (handled by callback)
  • SEND_REPLY_DATAGRAM: load and send Read Stream Reply OK
  • PUMPING: load and send next data chunk
  • SEND_COMPLETE: send Stream Data Complete
  • WRITE_WAIT_STREAM_INITIATE: waiting for inbound stream (callback)
  • WRITE_RECEIVING: receiving data (callback)
  • WRITE_SEND_REPLY: load and send Write Stream Reply OK

◆ ProtocolConfigMemStreamHandler_check_timeouts()

void ProtocolConfigMemStreamHandler_check_timeouts ( uint8_t current_tick)

Checks for timed-out config-mem stream operations.

If the active operation is in WAIT_INITIATE_REPLY, PUMPING, WRITE_WAIT_STREAM_INITIATE, or WRITE_RECEIVING and the elapsed time exceeds the timeout threshold, terminates the stream (if open) and resets to idle.

* @param current_tick  Current value of the global 100ms tick counter.

◆ ProtocolConfigMemStreamHandler_on_initiate_request()

bool ProtocolConfigMemStreamHandler_on_initiate_request ( openlcb_statemachine_info_t * statemachine_info,
stream_state_t * stream )

Routes Stream Initiate Request.

Routes Stream Initiate Request between config-mem and user.

For read streams, this module is always the source (outbound), so inbound initiate requests are never ours. For write streams, the remote initiates an inbound stream to us after we ACK the Write Stream Command datagram. We match by phase and remote alias.

* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
* @param stream             Pointer to stream_state_t entry.
*
Returns
true to accept, false to reject.

Routes Stream Complete or error.

Routes Stream Complete between config-mem and user.

For write streams, completion means all data has been received. Transition to WRITE_SEND_REPLY so the pump sends the Write Reply OK. For read streams, the remote end closed early – reset to idle.
