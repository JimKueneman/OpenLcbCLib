Implements the OpenLCB Stream Transport Standard (Feb 2026). Manages a fixed-size table of stream state entries, handles initiation negotiation, flow-controlled data transfer, and stream completion. All application interaction is through optional DI callbacks.

Initializes the Stream Transport protocol layer.

Stores the callback interface. Call once at startup.

Algorithm:

  1. Store pointer to callback interface
  2. Clear the stream state table
  3. Reset the DID counter
* @param interface_protocol_stream_handler  Pointer to callback interface structure.
*
Warning
Pointer must remain valid for lifetime of application.
NOT thread-safe – call during single-threaded initialization only.

◆ ProtocolStreamHandler_initiate_request()

void ProtocolStreamHandler_initiate_request ( openlcb_statemachine_info_t * statemachine_info)

Handles incoming Stream Initiate Request (MTI 0x0CC8).

Algorithm:

  1. Extract max_buffer_size (bytes 0-1), flags (bytes 2-3), SID (byte 4)
  2. If payload >= 6, extract proposed DID (byte 5)
  3. If payload >= 12, extract 6-byte Stream Content UID (bytes 6-11)
  4. If no on_initiate_request callback, reject with streams not supported
  5. Allocate a stream state entry; if table full, reject with buffer unavailable
  6. Assign a DID, populate stream state
  7. Call on_initiate_request callback
  8. Send accept reply with negotiated buffer size
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
*

◆ ProtocolStreamHandler_initiate_reply()

void ProtocolStreamHandler_initiate_reply ( openlcb_statemachine_info_t * statemachine_info)

Handles incoming Stream Initiate Reply (MTI 0x0868).

Algorithm:

  1. Extract max_buffer_size (bytes 0-1), flags (bytes 2-3), SID (byte 4), DID (byte 5)
  2. Find stream state entry by SID and remote node ID
  3. If not found, ignore (stale or unknown reply)
  4. If flags indicate accept (0x8000 or 0x0000 with non-zero buffer), transition to OPEN
  5. If reject, free the stream state entry
  6. Notify application callback
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
*

◆ ProtocolStreamHandler_data_send()

void ProtocolStreamHandler_data_send ( openlcb_statemachine_info_t * statemachine_info)

Handles incoming Stream Data Send (MTI 0x1F88).

Algorithm:

  1. Extract DID from byte 0 of payload
  2. Find stream state entry by DID and remote node ID
  3. If not found, ignore
  4. Track bytes received (payload_count - 1 for the DID byte)
  5. Decrement bytes_remaining by data length
  6. Notify application callback
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
*

◆ ProtocolStreamHandler_data_proceed()

void ProtocolStreamHandler_data_proceed ( openlcb_statemachine_info_t * statemachine_info)

Handles incoming Stream Data Proceed (MTI 0x0888).

Algorithm:

  1. Extract SID (byte 0) and DID (byte 1) from payload
  2. Find stream state entry by SID and remote node ID (we are source)
  3. If not found, ignore
  4. Extend send window by max_buffer_size
  5. Notify application callback
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.

void ProtocolStreamHandler_data_complete ( openlcb_statemachine_info_t * statemachine_info)

Handles incoming Stream Data Complete (MTI 0x08A8).

Algorithm:

  1. Extract SID (byte 0) and DID (byte 1) from payload
  2. Find stream by SID+remote (if we are destination) or DID+remote (if we are source)
  3. If not found, ignore
  4. Notify application callback
  5. Free the stream state entry
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.

◆ ProtocolStreamHandler_handle_terminate_due_to_error()

void ProtocolStreamHandler_handle_terminate_due_to_error ( openlcb_statemachine_info_t * statemachine_info)

Handles Terminate Due To Error for stream-related MTIs.

Per StreamTransportS Section 7.4, a stream is closed if:

  1. The destination sends TDE with rejected_mti = MTI_STREAM_SEND
  2. The source sends TDE with rejected_mti = MTI_STREAM_PROCEED

Algorithm:

  1. If payload < 4 bytes, return (no rejected_mti field)
  2. Extract rejected_mti from bytes 2-3
  3. If not a stream MTI, return
  4. Scan stream table for entries matching remote node ID
  5. For each match, notify on_complete callback and free the entry
* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
*

stream_state_t * ProtocolStreamHandler_initiate_outbound ( openlcb_statemachine_info_t * statemachine_info,

uint16_t proposed_buffer_size,
uint8_t suggested_dest_stream_id,
const uint8_t * content_uid )

Opens an outbound stream where this node is the source.

Algorithm:

  1. Allocate a stream state entry; return NULL if table full
  2. Assign a SID, populate state with is_source=true, INITIATED
  3. Send Stream Initiate Request to the destination
  4. Return pointer to stream state entry

The caller waits for on_initiate_reply to learn accept/reject.

* @param statemachine_info         Pointer to openlcb_statemachine_info_t context.
* @param dest_alias                CAN alias of the destination node.
* @param dest_id                   Node ID of the destination node.
* @param proposed_buffer_size      Proposed max buffer size.
* @param suggested_dest_stream_id  Suggested DID (0xFF if no preference).
*
Returns
Pointer to allocated stream_state_t, or NULL if table full.

Sends data on an open stream where this node is the source.

Algorithm:

  1. Validate stream is non-NULL, OPEN, and is_source
  2. Validate data_len fits within bytes_remaining
  3. Build and send Stream Data Send message
  4. Update bytes_transferred and bytes_remaining

* @param stream             Pointer to the stream state entry.
* @param data               Pointer to data bytes to send.
* @param data_len           Number of data bytes.
*
Returns
true if data was sent, false if precondition failed.

bool ProtocolStreamHandler_send_early_proceed ( openlcb_statemachine_info_t * statemachine_info,
stream_state_t * stream )

Sends an early Stream Data Proceed to allow double-buffering.

Per StreamTransportS Section 7.3, the destination may send one advance Proceed before the full buffer window is consumed. This extends the source's send window by max_buffer_size. Only valid when this node is the destination and the stream is OPEN.

* @param statemachine_info  Pointer to openlcb_statemachine_info_t context.
* @param stream             Pointer to the stream state entry.
*
Returns
true if Proceed was sent, false if precondition failed.
