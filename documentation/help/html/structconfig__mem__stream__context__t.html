Detailed Description

Tracks the state of one config-mem stream operation (read or write).

A pool of these contexts is allocated in the module, sized by USER_DEFINED_MAX_CONCURRENT_ACTIVE_STREAMS. Multiple config-mem stream operations can be active concurrently. The phase enum distinguishes read vs write operations. Each active context is linked to its Layer 1 stream via stream->context.
