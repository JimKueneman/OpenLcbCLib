Implements the packing and unpacking of detector Event IDs as specified in the OpenLCB DCC Detection Protocol Working Note. Each Event ID is an 8-byte value: 6 bytes of detector unique ID, 2 direction/occupancy bits, and 14 bits of DCC address.

dcc_detector_direction_enum direction,
uint16_t raw_address_14 )

Builds a DCC detector Event ID from its components.

Algorithm:

  1. Shift the 48-bit detector node ID into the upper 6 bytes of a 64-bit value
  2. Shift the 2-bit direction field into bits [15:14]
  3. Mask the 14-bit raw address into bits [13:0]
  4. OR all three fields together
* @param detector_node_id 48-bit node ID of the detector
* @param direction dcc_detector_direction_enum occupancy status
* @param raw_address_14 14-bit DCC address field (already includes type prefix)
*
Returns
Assembled event_id_t

dcc_detector_address_type_enum OpenLcbApplicationDccDetector_extract_address_type ( event_id_t event_id)

Determines the DCC address category from a detector Event ID.

Algorithm:

  1. Extract the 14-bit raw address from the lower bits
  2. Check for the track-empty sentinel (0x3800)
  3. Check the upper 6 bits for short-address prefix (0x38)
  4. Check the upper 6 bits for consist-address prefix (0x39)
  5. Otherwise classify as long address
* @param event_id event_id_t to decode
*
Returns
dcc_detector_address_type_enum category

uint16_t OpenLcbApplicationDccDetector_extract_dcc_address ( event_id_t event_id)

Extracts the usable DCC address from a detector Event ID.

Algorithm:

  1. Extract address type to determine decoding
  2. For short and consist addresses, mask off the prefix to get the 8-bit address
  3. For track-empty, return 0
  4. For long addresses, return the full 14-bit value
* @param event_id event_id_t to decode
*
Returns
DCC address value (meaning depends on address type)
